# FeedBar (original prototype)

This repository holds the January 2026 prototype that became **FeedsBar**, a live news ticker for the Mac desktop.

The shipping product, downloads and the Signal 500 source catalogue live at **https://feeds.bar**.

- Product: https://feeds.bar
- Signal 500, the hand-scored source list with OPML packs: https://feeds.bar/signal-500/
- Engineering notes: https://feeds.bar/engineering/shazamkit-provisioning/
